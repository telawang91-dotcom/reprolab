# 01・产品需求文档（PRD）

ReproLab 合并版 v3.0 —— 骨架承自 ReproLab（Python 全栈、好落地），机制融合 SciData Agent（溯源账本、对抗式质检、RRF 检索、模型无关）。

面向个人开发・demo 优先・运维从简。

### 1. 定位与叙事

#### 1.1 一句话定位

ReproLab 是一个面向研究生的、可信可复现、会自我核查、越用越懂你的科研工作台。

别人做 "科研版 ChatGPT（帮你查、帮你聊）"；我们做 "从检索到验证的科研闭环"。

#### 1.2 核心叙事（路演主口号）

"可信由架构保证，而非由模型保证。"

因果链：我们要跑更便宜、更易幻觉的国产模型（混元 / DeepSeek）→ 幻觉风险更高 → 于是 "溯源账本 + 对抗式质检" 从锦上添花变成刚需 → 换用任何模型，可信度都由架构托底。

这也解释了为什么 "溯源 + 自校验" 不是加分项，而是产品的地基。

#### 1.3 背景与痛点

研究生科研 "记不住、说不清、重不来"：

1. 半年前的分析重跑不出来、忘了怎么跑；
2. 导师问 "数据哪来的、可信吗" 答不上；
3. 文献太多找观点翻半天；
4. 不太会写代码，数据分析卡壳；
5. 论文里数字抄错、图和数据对不上；
6. 直接用通用大模型：编造引用、来路不明的数字、图码不符 —— 科研场景零容忍。

#### 1.4 目标用户

有数据分析需求的研究生（跨学科通用）。演示主场景用通俗数据集（Palmer Penguins），保证零门槛可看懂。

#### 1.5 交付形态

一个能现场演示、把故事讲清楚的 Demo；Agent 核心是重点与亮点。

架构上把 "Agent 核心" 与 "UI 外壳" 解耦：核心以 REST 暴露、可脚本调用（M-Platform 适配层），UI 是能力的展示层，重点可视化 "溯源" 与 "自校验"。

### 4. 竞品与差异化

三类竞品形态：

1. 知识库问答（腾讯 ima）：被动问答、多知识空间、中文成熟。解决 "资料在哪"，不解决 "能不能主动、可信地把活干完"。
2. 闭源垂直科研 Agent（Claude Science）：能力强（溯源可复现、自校验、多学科渲染、连 HPC），但偏生命科学、闭源、国外云端、模型绑定。
3. 通用 RAG / ChatGPT 类：泛而不专，检索停留在朴素向量召回，缺 RRF/reranker，数字与引用来路不明，无长期记忆与产物血缘。

ReproLab 的独占区间 = 主动执行 × 可信可审 × 模型无关 × 轻量可落地。

四条差异化护城河：① 主动多智能体执行 vs 被动问答；② 模型无关架构（可跑便宜模型）；③ 溯源账本 + 对抗式质检（"可信由架构保证"）；④ 学科无关、轻量本地、数据不出端。

学它（Claude Science）的 "溯源 + 自校验" 内核，做中文科研场景 + 研究生日常 + 可落地版本。

### 5. 非功能需求（demo 口径）

1. 单次分析（小数据集）端到端 < 30s。
2. 沙箱：内存 / CPU 限制、30s 超时、默认无网络。
3. 数据隐私：数据留本地，仅 LLM API 出网（卖点）。
4. 可扩展：执行器 / 技能包 / LLM 均可插拔。
5. 运维从简：demo 阶段不做队列 / 高可用 / 多用户并发；异步任务用 FastAPI BackgroundTasks。
6. 可诊断：前端不可直出底层网络错误；当后端、数据库、模型或沙箱不可用时，应说明受影响能力与恢复操作。
7. 上手成功：首次用户可在十分钟内完成“选择示例或上传资料 → 提出分析问题 → 获得带血缘产物 → 通过校验的结论”中的可演示闭环；示例体验不得污染真实工作区。
8. 交付质量：每次代码变更必须通过后端单测、前端类型检查和生产构建；数据库/沙箱完整闭环由可手动触发的集成验收验证。

### 7. 验收剧本（3 分钟 demo）

1. 上传论文 + 数据，说 "帮我复现图 3 的分析" → Agent 检索、写代码、出图。（M1/M2/M3/M4）

2. 点开这张图 → 展开完整溯源 DAG（数据 / 代码 / 环境 / 对话）。（M5/M6）

3. 🎯 换掉一个数据文件 → 一键重跑 → 平台自动标红 "结果与原图不一致"。（招牌高光）

4. 🎯 让它写一段结论 → 校验 Agent 把编造的数字标红 "无法溯源"、把假引用标红 "未命中知识库"。（M7）

5. 结论确认 → 一键回写知识库，闭环完成；工作台出现新的科研建议。（M8/M10）

   

   6.（可选）现场把主模型从混元切到 DeepSeek 重跑同一任务，溯源结论依然成立。（M-Platform）

### 8. 演示素材（锁定，可彩排）

1. 主数据集：Palmer Penguins（penguins.csv，公开）。三物种形态测量，适合 "分组显著性检验 + 箱线图"。
2. 配套 "文献"：1 篇开放获取短文 PDF（或自制一页说明）入库，演示检索 + 引用。
3. "图 3" = 三物种体重（body_mass_g）箱线图 + 组间显著性检验（ANOVA /t 检验）。
4. 触发漂移（高光）：备 penguins_modified.csv（删物种或改数值），替换后一键重跑 → 结论变 → 标红。
5. 触发自校验标红：让 Agent 写结论时故意引入数据里没有的数字 → 校验标红。
