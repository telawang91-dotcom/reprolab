# M12 研究项目工作区（P1）

## 目标

把当前固定的 demo `project_id` 升级为用户可创建、切换、归档的研究项目。项目是资料、知识空间、数据集、运行、产物、结论和记忆的硬隔离边界；任何列表、检索、问答、分析与血缘读取均必须继承当前项目作用域。

## 开工前必须更新的唯一事实来源

本卡只定义范围，不重复 DDL 或接口契约。实施前先更新：

1. `docs/03-DATA-MODEL.md`：projects 表、归档状态、默认项目迁移和外键约束；
2. `docs/04-API.md`：项目 CRUD、当前项目切换和全部现有接口的 project scope 行为；
3. `docs/06-DESIGN.md`：顶部项目切换器、归档确认、跨项目空状态。

## 研发 DoD

1. API 提供创建、列表、重命名、归档与恢复；删除不得默默销毁带产物的研究记录。
2. 前端顶部项目名称为真实可切换项目，不再显示不可操作的“默认项目”。切换后全局缓存清空、数据重新读取。
3. 本地演示项目与真实项目分离；演示资料不可被写入真实知识库、记忆或建议。
4. 所有 project_id 由当前工作区上下文注入，禁止散落硬编码 UUID。

## 测试 DoD

1. 两个项目各自上传同名资料、运行同类分析，检索、问答、产物、血缘和结论均不得串项目。
2. 归档项目不可写入，但可只读查看；恢复后历史血缘仍完整。
3. 切换项目时不得短暂显示前一项目的缓存内容。
4. 首次用户、空项目、示例项目、归档项目、网络中断切换均有可读空态或错误态。
